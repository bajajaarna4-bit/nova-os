Zero-Trust Architecture

Enforcing SELinux policies by default, isolated systemd sandboxes, and polkit privilege elevation. Every privileged request is audited and authorized.

✨

Local-First Intelligence

Private system assistant running local Ollama inference or optional Gemini connections. Strict allowlisted tools prevent arbitrary command execution.

🔄

Atomic Deployments

Immutable root file system managed by bootc and rpm-ostree. Updates are signed, atomic, and automatically roll back if a boot integrity check fails.

Subsystem Architecture

Strict interface isolation between Rust system daemons, D-Bus session bus, and the desktop shell.
